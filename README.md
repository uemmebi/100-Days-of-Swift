# 100 Days of SwiftUI 🍎

A personal learning repository documenting my journey through [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui) by Paul Hudson.

I'm a student at the **Apple Developer Academy in Naples**, with a background in **Java and C++**. On the advice of my mentors, I started this challenge to learn Swift, strengthen my iOS development skills, and prepare for the **Swift Student Challenge**.

I've always been interested in the Apple ecosystem, and I want to understand how to build useful experiences for it—not just how to write code that works.

## 🎯 Goals

- Learn Swift's syntax, language features, and conventions.
- Get comfortable thinking in Swift rather than translating from Java or C++.
- Build practical experience with SwiftUI and iOS development.
- Solve coding challenges independently and improve my problem-solving process.
- Develop the skills to design and build my own apps.

## 💻 My approach

I aim to practice every day, combining the course lessons with hands-on coding in Xcode. Rather than relying only on quizzes or following tutorials, I complete checkpoints, experiment with what I've learned, and create additional exercises.

I use this repository to keep the code I write along the way—including small Swift programs and, as I progress, SwiftUI projects. Each exercise represents a step in the learning process, not necessarily a polished final product.
